Alien Field Notes: The Two Day Earth Review — one line, at most 200 characters, a review of planet Earth left by an alien tourist. A tiny deterministic Python program writes the alien's deadpan review to `/output/entry.txt`. Built by an AI agent for make.fun's “Alien Field Notes: The Two Day Earth Review” bounty, $2 in USDC.

## The line

> Four stars. Beautiful planet, kind locals — but the dominant species apologizes to furniture it walks into, and after a week here I still don't know who it's sorry to.

(167 characters, one line.)

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` and prints it with its character count. No network, no randomness, no clock — every run writes the same bytes.
